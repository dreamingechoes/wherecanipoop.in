# 💩 Where Can I Poop In?

Find clean nearby toilets fast with Where Can I Poop In?—your funny, friendly bathroom locator with real reviews and ratings. Never get caught without a place to go!

---

## 🚀 Features

- ✨ Clean, responsive UI built with TailwindCSS
- ⚛️ React + Vite + TypeScript
- 📥 Join waitlist via email collection (NoCodeForm integration)
- 🎯 Clear CTA and modern layout
- 🌐 Open Graph tags for rich social sharing

---

## 🛠 Tech Stack

- [React](https://reactjs.org/)
- [Vite](https://vitejs.dev/)
- [TypeScript](https://www.typescriptlang.org/)
- [Tailwind CSS](https://tailwindcss.com/)
- [NoCodeForm](https://nocodeform.io) for email collection

---

## 📦 Getting Started

```bash
git clone https://github.com/your-username/where-can-i-poop-in.git
cd where-can-i-poop-in
npm install
npm run dev
```

Then open your browser at [http://localhost:5173](http://localhost:5173)

---

## 🔒 Email Collection

Emails are submitted to [NoCodeForm](https://nocodeform.io), a backendless form service. You can replace this with your own backend later if desired.
